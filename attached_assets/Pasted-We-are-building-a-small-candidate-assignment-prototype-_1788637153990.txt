We are building a small candidate-assignment prototype called "CogniBloom – Active Learning Tutor".

Read the following product requirements carefully before making changes:

The application must improve the learning experience after an AI explanation instead of allowing the student to simply read the answer and leave.

Core flow:

1. Student enters or selects a learning topic.
2. Student asks a question.
3. System provides an explanation.
4. Student interacts with an active-learning mechanism.
5. System evaluates the interaction and gives an appropriate response.
6. Student can continue or finish the learning session.

We are intentionally building a SMALL, polished prototype rather than a large application.

TECH STACK:
- Frontend: React + TypeScript + Vite
- Styling: Tailwind CSS
- Backend: Node.js + Express + TypeScript
- Database: SQLite
- ORM: Prisma
- REST APIs
- AI responses will initially be mocked. Do NOT integrate an external LLM API.
